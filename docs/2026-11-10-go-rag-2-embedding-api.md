## 一、Embedding API 长什么样

业界事实标准就是 OpenAI 定义的 `/v1/embeddings`：POST 一个 JSON，传入模型名和文本（单条或数组），返回等数量的浮点数组。因为够简单，国内厂商几乎全部做了兼容实现——改个 `baseURL` 就能切换供应商。

实测踩坑记录（2026-11-10 本机验证）：我们 `.env` 里配的是 DeepSeek 对话端点，但它**没有** `/v1/embeddings`（请求返回 404）；OpenAI 官方在本机网络不可达。最终选用硅基流动（SiliconFlow，国内直连），其上 `BAAI/bge-m3` 嵌入模型截至发稿在官网价格页标注**免费**。`.env` 新增三行，与对话配置完全独立：

```bash
EMBED_BASE_URL=https://api.siliconflow.cn/v1
EMBED_API_KEY=你的Key
EMBED_MODEL=BAAI/bge-m3
```

一次真实调用的返回：`bge-m3` 输出 **1024 维**向量，四条短文本耗时约 500ms。以后每篇代码都从这里读凭证，切换供应商只改环境变量。

## 二、模型选型：先收藏这张表

Embedding 模型不是越贵越好，看维度、上下文上限、价格和语言场景。写文当天核对官方文档后的主流选项：

| 模型 | 维度 | 输入上限 | 价格（输入/百万 token） | 特点 |
| --- | --- | --- | --- | --- |
| OpenAI `text-embedding-3-small` | 1536 | 8192 | $0.02 | 性价比首选，英文通用 |

两个关键认知：

1. **没有 "text-embedding-4"**。OpenAI 官方文档至今只列第三代两个模型，网上流传的四代是臆测，选型时以官方模型页为准。
2. **查询和文档必须用同一个模型**。向量空间是模型私有的，跨模型比较相似度毫无意义——这也是换模型必须重建整个索引的原因（第 4 篇会再强调）。

## 三、Go 调用：薄封装 + 批量 + 缓存

仓库已固定 `openai-go v3`（v3.89.0，写文当天 `go doc` 核对的 API 面）。核心调用就几行，传入字符串数组一次嵌入多条：

```go
resp, err := c.cli.Embeddings.New(ctx, openai.EmbeddingNewParams{
	Model: openai.EmbeddingModel(c.model), // 如 "BAAI/bge-m3"
	Input: openai.EmbeddingNewParamsInputUnion{OfArrayOfStrings: inputs},
})
// resp.Data 与 inputs 按下标一一对应，取 item.Embedding 即向量
```

但直接把这几行撒进业务代码会埋三个坑：**重复文本重复扣费、上千条文本串行慢、缓存缺失**。我们的封装 `rag/embedding/embedding.go` 处理了批量与磁盘缓存——同一文本的嵌入结果以 `模型名+文本` 的 SHA-256 为文件名落盘，命中缓存就绝不请求 API：

```go
for i, t := range texts {
	if v, ok := c.load(t); ok {
		vecs[i] = v // 命中缓存，免费
	} else {
		missIdx = append(missIdx, i) // 未命中，攒批
	}
}
// 未命中的按 32 条一批合并请求，减少往返
```

余弦相似度这次写全量版本（不对输入做归一化假设，任何模型的输出都能算）：

```go
// Cosine 计算两个向量的余弦相似度，值域 [-1,1]，越接近 1 语义越相近。
func Cosine(a, b []float64) (float64, error) {
	var dot, na, nb float64
	for i := range a {
		dot += a[i] * b[i]
		na += a[i] * a[i]
		nb += b[i] * b[i]
	}
	return dot / (math.Sqrt(na) * math.Sqrt(nb)), nil
}
```

## 五、成本压制的三板斧

Embedding 虽便宜，规模化后照样要钱。三个惯用手段，按见效快慢排：

1. **磁盘缓存**：同一文本绝不请求第二次。我们的封装已内置，缓存目录 `.embed-cache/`。
2. **批量请求**：一次调用传 N 条文本，省 N-1 次 HTTP 往返；SDK 限制单请求 30 万 token 总量，我们按 32 条一批切。
3. **dimensions 截断**：OpenAI 第三代模型支持 `dimensions` 参数把 3072 维截到 1024 维，语义损失很小，存储和计算省 2/3——Matryoshka 特性，免费的午餐。

以本仓库 16 篇文章、约 6 万字符估算：嵌入一遍的成本以分钱计甚至零元（bge-m3 免费档），真正的成本在**每次查询都要现 embed 一次查询向量**——所以查询侧缓存（同问句直接命中）是第 7 篇生产化要补的课。
