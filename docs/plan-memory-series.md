# Agent 记忆系统系列 · 8 篇规划（2026-11-26 定）

主线案例贯穿：以「AI 模拟面试教练需要记住用户」为产品需求——单次面试内记住答过什么（短期），跨会话记住薄弱维度（长期），第 8 篇把完整记忆系统装进面试教练。
技术红线：只用 openai-go（写文当天核对版本）+ 标准库；代码必须真实编译运行；向量部分只做「复用 RAG 系列成果」的引用，不重复展开。

与已有系列的边界（防撞车）：
- 面试教练 #2 的「多轮记忆」只是滑动窗口 → 本系列第 2 篇讲窗口之外的摘要压缩，明确升级关系。
- RAG 系列的向量检索是「读外部知识」→ 本系列是「写读自身经历」，第 4 篇检索策略直接引用 RAG #6 的 RRF，不重新推导。
- 多智能体 #4 共享黑板是「多 Agent 工作内存」→ 本系列讲单 Agent 跨时间记忆，第 1 篇用一张表划清两者边界。
- LLM 工程化 #5 语义缓存是「省钱的只读副本」→ 第 1 篇同一张表里划清缓存 vs 记忆。
